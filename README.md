# دليل منتزه الردف

دليل عربي مستقل لمنتزه الردف بالطائف، مبني بـ Astro وCloudflare Workers. لا يمثل المشغّل.

## التشغيل

نسختا التشغيل المعلنتان: Node 24.19.0 وpnpm 11.23.0. استخدم `pnpm install --frozen-lockfile` ثم `pnpm check` و`pnpm build`. النطاق الافتراضي `https://ruddafpark.com`، ويمكن تحديد `SITE_URL` عند البناء. اسم Worker هو `ruddafpark`، وASSETS يستخدم `dist/client` مع تشغيل Worker أولًا لمعالجة التوجيه و404. النشر يعتمد على إعداد المشروع الفعلي في Cloudflare.

## المصادر والمرئيات

لقطة خرائط جوجل العامة بتاريخ 21 أكتوبر 2026 تخص قائمة المنتزه، ولا تثبت مواعيد عروض النافورة أو شروط التذاكر. المصادر الرسمية التاريخية مذكورة بتاريخها على الصفحات. الرسوم أصلية وتوضيحية وليست صورًا للمكان أو خرائط دقيقة؛ صفحة الصور تربط بالمصدر العام دون نسخ الصور أو المراجعات.

## الخصوصية

إحصاءات جوجل اختيارية ويمكن سحب الموافقة في صفحة الإعدادات. قد تضيف الاستضافة Cloudflare Web Analytics بصورة مستقلة؛ لا يتحكم به مفتاح جوجل. الخريطة تُحمّل عند الطلب. الطقس يُجلب من Open-Meteo على الخادم لإحداثيات ثابتة؛ لا يطلب موقع جهاز الزائر. عامل الخدمة يخزن الهوية والرسوم فقط، ولا يخزن صفحات الطقس والزيارة الديناميكية.
