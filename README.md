# دليل منتزه الردف

مشروع Astro عربي مستقل وغير ربحي لمنتزه الردف في الطائف، مصمم للنشر على Cloudflare Workers.

> **ملاحظة تحقق:** تعذر على بيئة الإنشاء الحالية الوصول إلى سجل npm، لذلك لا تتضمن هذه الحزمة ملف قفل مُولّدًا ومتحققًا منه. راجع `QA_STATUS.md` و`qa/install-attempt.log` قبل اعتمادها للإنتاج.

## المتطلبات المثبتة

- Node.js: `24.19.0`
- pnpm: `11.23.0`
- Astro: `7.2.6`
- Tailwind CSS: `4.3.3`
- TypeScript: `6.0.3`

## إعداد النطاق

النطاق يُضبط في مكان واحد فقط عبر متغير البيئة `SITE_URL`. عند غيابه يبقى المشروع قابلاً للبناء، ولا تُولّد روابط canonical أو Open Graph المطلقة، كما لا يتم تفعيل تكامل sitemap. بعد تحديد النطاق، اضبط `SITE_URL` في بيئة البناء وأعد البناء.

## أوامر المشروع

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm check
pnpm build
pnpm deploy
```

## الخصوصية والتحليلات

معرّف GA4 هو `G-HXM22WWPKP`، لكن مكتبة Google Analytics لا تُحمّل إلا بعد موافقة الزائر من صفحة `/cookies/`.

## الصور

الصور الحقيقية الظاهرة في الصفحة مرتبطة بمصادر نشر خارجية ومذكور مصدر كل صورة في واجهة الموقع. الهوية البصرية والأيقونات وملفات favicon محلية داخل `public/brand/`.
